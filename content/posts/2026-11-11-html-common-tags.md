## 07 · 强调重要性标签以及注释标签

### 强调标签

- `<strong>`：**加粗强调**，表示内容重要，浏览器默认加粗。
- `<em>`：*斜体强调*，表示语气上的强调，浏览器默认斜体。
- 对比：
  - `<b>` / `<i>`：只是**视觉上**加粗/斜体，没有语义，HTML5 里不推荐用。
  - `<strong>` / `<em>`：有**语义**，告诉搜索引擎和屏幕阅读器"这段内容重要"，样式问题交给 CSS 控制。
- **原则**：要语义就用 strong/em，要纯装饰就用 CSS，别用 b/i。

### 注释标签

```html
<!-- 这是一段注释，浏览器不会显示 -->
```

- 注释写给自己和同事看，用于：临时注释掉一段代码、标注模块说明、写 TODO。
- 快捷键：VS Code / Trae 里 `Ctrl + /` 一键注释/取消注释当前行。
- **注意**：HTML 注释在网页源代码里能被用户看到（右键 → 查看网页源代码），别写密码、敏感信息。

## 08 · 元素分类以及歌曲彩蛋

HTML 元素按**显示方式**分三大类：

### 1. 块级元素（block）

- 独占一行，从上到下排列。
- 可以设置 `width`、`height`、`margin`、`padding`。
- 不设宽度时默认占满父容器 100%。
- 常见：`div`、`h1~h6`、`p`、`ul`、`ol`、`li`、`table`、`form`、`header`、`footer`。

### 2. 行内元素（inline）

- 不独占一行，多个行内元素并排，直到撑满换行。
- **不能**直接设置 `width`、`height`，宽高由内容撑开。
- 常见：`span`、`a`、`strong`、`em`、`b`、`i`。

### 3. 行内块元素（inline-block）

- 既有行内元素的并排特性，又能设置宽高。
- 常见：`img`、`input`、`button`。

### 互相转换

通过 CSS 的 `display` 属性切换：
```css
div { display: inline; }    /* 块级转行内 */
span { display: block; }    /* 行内转块级 */
img { display: inline-block; } /* 默认就是行内块 */
```

> 彩蛋环节：用纯 HTML 标签写了个"歌曲播放页"小demo，把前几节学的标签串起来练手。

## 09 · 图像标签以及常见格式

### img 标签

```html
<img src="images/cat.jpg" alt="一只橘猫" title="鼠标悬浮显示的文字" width="300">
```

- **单标签**，自闭合，没有结束标签。
- **常用属性**：
  - `src`：图片路径（source），必填。
  - `alt`：图片加载失败时显示的替代文字，**SEO 和无障碍必备**。
  - `title`：鼠标悬停时的提示文字。
  - `width` / `height`：宽高，只设一个另一个会等比缩放，防止图片变形。
- **注意**：`img` 是行内块元素，底部默认有几像素缝隙（基线对齐导致），后面学 CSS 再解决。

### 常见图片格式对比

| 格式 | 特点 | 适用场景 |
|---|---|---|
| **JPG / JPEG** | 有损压缩，不支持透明 | 照片、风景图、色彩丰富的图 |
| **PNG** | 无损压缩，支持透明背景 | Logo、图标、需要透明的图 |
| **GIF** | 支持简单动画、256色 | 动图、表情包 |
| **WebP** | 同时支持有损/无损和透明，体积比 JPG/PNG 小 30% 左右 | 现代网站首选，兼容性已很好 |
| **SVG** | 矢量图，放大不模糊，代码格式 | Logo、图标、插画 |

**选择建议**：照片用 WebP/JPG，图标 Logo 用 SVG，需要透明位图用 PNG。

## 10 · 路径分类

写 `src`、`href` 时怎么找文件，分两种：

### 相对路径（相对于当前 HTML 文件的位置）

- **同级目录**：图片和 html 在同一个文件夹
  ```html
  <img src="cat.jpg">
  ```
- **下级目录**：图片在 html 文件夹里的子文件夹
  ```html
  <img src="images/cat.jpg">
  ```
- **上级目录**：图片在 html 的上一级文件夹，用 `../` 返回一级
  ```html
  <img src="../images/cat.jpg">   <!-- 往上退一级 -->
  <img src="../../images/cat.jpg"> <!-- 往上退两级 -->
  ```

### 绝对路径

- **本地绝对路径**：`C:\Users\xxx\Desktop\cat.jpg`，**项目里不要用**，换台电脑就挂了。
- **网络绝对路径**：完整 URL
  ```html
  <img src="https://example.com/cat.jpg">
  ```
  适合引用网上的图（但要注意防盗链和稳定性）。

**原则**：项目内部一律用相对路径；外部资源才用网络 URL。

## 11 · 音视频标签以及下载方式

### audio 音频标签

```html
<audio src="music.mp3" controls loop muted>
  你的浏览器不支持 audio 标签
</audio>
```

- **常用属性**：
  - `controls`：显示播放器控制面板（必填，不然用户没法点）
  - `autoplay`：自动播放（浏览器大多拦截带声音的自动播放，要配合 `muted`）
  - `loop`：循环播放
  - `muted`：静音
- **兼容多格式**：用 `<source>` 标签
  ```html
  <audio controls>
    <source src="music.mp3" type="audio/mpeg">
    <source src="music.ogg" type="audio/ogg">
  </audio>
  ```

### video 视频标签

```html
<video src="video.mp4" controls width="600" poster="cover.jpg">
  你的浏览器不支持 video 标签
</video>
```

- 属性和 audio 基本一致，多一个：
  - `poster`：视频加载前显示的封面图。

### 支持的格式

- 音频：MP3（最通用）、WAV、OGG
- 视频：MP4（H.264，最通用）、WebM、OGG

> 不写 `controls` 属性音视频就完全不可见不可控；要自动播放就得加 `muted`，否则浏览器自动拦截。

## 12 · 创建超级链接以及锚点链接

### a 标签基础

```html
<a href="https://www.baidu.com" target="_blank">点我去百度</a>
```

- `href`：跳转目标地址（hyper reference）。
- `target`：
  - `_self`（默认）：当前标签页跳转。
  - `_blank`：新标签页打开。
- **写外部链接一定要加 `https://`**，只写 `www.baidu.com` 会被当成相对路径。

### 四种常见 href 写法

1. **跳转到外部网站**：`<a href="https://...">`
2. **跳转到本地 html 页面**：`<a href="about.html">`（相对路径）
3. **空链接**：`<a href="#">`，回到页面顶部
4. **下载文件**：`<a href="music.zip" download>点击下载</a>`，加 `download` 属性触发下载

### 锚点链接（页内跳转）

用来做目录、回到顶部：

```html
<!-- 1. 给目标位置加 id -->
<h2 id="chapter1">第一章</h2>

<!-- 2. 链接 href 写 #id名 -->
<a href="#chapter1">跳到第一章</a>

<!-- 回到顶部 -->
<a href="#">回到顶部</a>
```

- 常用于长文章目录、电商详情页"宝贝详情/评价/推荐"切换。
- SEO 里面包屑导航也常用 a 标签。

## 13 · 网页结构标签和无语义标签

### 无语义标签

- `<div>`：块级盒子，没有任何语义，是页面布局最常用的"容器"。
- `<span>`：行内容器，用来包一小段文字单独设置样式。
- 特点：本身不带任何样式和含义，纯靠 CSS 控制。

### 有语义的结构标签（HTML5 新增）

一个典型网页布局：

```html
<body>
  <header>页头：Logo、导航、横幅</header>
  <nav>导航栏</nav>
  <main>
    <article>文章主体（一篇独立的内容）</article>
    <aside>侧边栏：推荐、广告</aside>
  </main>
  <footer>页脚：版权、联系方式</footer>
</body>
```

| 标签 | 作用 |
|---|---|
| `<header>` | 页面或某个区块的头部 |
| `<nav>` | 导航链接区 |
| `<main>` | 页面主体内容（一个页面只一个） |
| `<article>` | 一篇独立完整的文章/帖子 |
| `<section>` | 页面里的一个区块/章节 |
| `<aside>` | 侧边栏，跟主内容相关但独立 |
| `<footer>` | 页面或区块底部 |

**意义**：和全用 `<div class="header">` 比，语义标签让代码可读性更强，对 SEO 和屏幕阅读器更友好。

## 14 · 列表标签 —— 有序、无序和描述列表

### 无序列表 ul

- 列表项前面默认是小圆点。
- 常用于：导航菜单、商品列表、文章目录。

```html
<ul>
  <li>苹果</li>
  <li>香蕉</li>
  <li>橘子</li>
</ul>
```

### 有序列表 ol

- 列表项前面默认是 1. 2. 3. 数字编号。
- 常用于：排行榜、操作步骤、说明书。

```html
<ol>
  <li>打开编辑器</li>
  <li>新建 html 文件</li>
  <li>写 Hello World</li>
</ol>
```

### 描述列表 dl

- 一组术语 + 描述，常用于：FAQ、名词解释、商品参数。

```html
<dl>
  <dt>HTML</dt>
  <dd>超文本标记语言，用来搭页面结构</dd>
  <dt>CSS</dt>
  <dd>层叠样式表，用来控制页面样式</dd>
</dl>
```

### 注意事项

- `<ul>` / `<ol>` 里面**只能直接放 `<li>`**，不能塞别的标签。
- `<li>` 里面可以放任何东西：p、img、div，甚至再套一个 ul（嵌套列表）。
- 小圆点/编号默认样式很难看，实际项目里都用 CSS 把 `list-style: none` 去掉，自己做样式。

## 15 · 表格标签和 AI 合并单元格

### 基本表格结构

```html
<table border="1">
  <thead>
    <tr>
      <th>姓名</th>
      <th>年龄</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>张三</td>
      <td>20</td>
    </tr>
    <tr>
      <td>李四</td>
      <td>22</td>
    </tr>
  </tbody>
</table>
```

- `<table>`：表格容器
- `<tr>`：表格行（table row）
- `<th>`：表头单元格，默认加粗居中
- `<td>`：普通单元格（table data）
- `<thead>`：表头区域
- `<tbody>`：表格主体
- `<tfoot>`：表格底部（可选）

### 合并单元格

两种合并方式：

1. **跨行合并**：`rowspan="2"` —— 当前单元格占 2 行
2. **跨列合并**：`colspan="2"` —— 当前单元格占 2 列

**规则**：
- 合并谁，就在谁身上写属性。
- 被合并掉的单元格要**删掉**，不然表格会错位。
- 先算清楚：要合并几行/几列，就从原位置删掉对应数量的 td。

例子：两列合并成一个表头
```html
<tr>
  <th colspan="2">学生信息表</th>
</tr>
```

> 表格现在主要用来展示结构化数据（课表、成绩单、价格表），**不要用 table 做页面布局**——那是十年前的做法，现在布局全靠 div + CSS。

## 今日小结

今天一口气学了 9 节，把 HTML 常用的实体标签基本过完了：

1. **文本类**：strong/em 强调、注释、div/span 容器
2. **媒体类**：img 图片（5 种格式怎么选）、audio/video 音视频
3. **链接类**：a 超链接、空链接、下载链接、页内锚点
4. **结构类**：header/nav/main/article/aside/footer 语义布局
5. **列表类**：ul 无序、ol 有序、dl 描述
6. **表格类**：table 结构 + rowspan/colspan 合并单元格
7. **核心概念**：块级/行内/行内块元素分类、相对/绝对路径

HTML 标签本身不难，难的是形成"语义化"意识——写的时候就想清楚这块该用什么标签，而不是全 div 糊上去。明天开始应该就进 CSS 了，期待。
