## 01 · Trae AI 编辑器介绍和安装

- **Trae 是什么**：字节跳动出的 AI 原生代码编辑器，基于 VS Code 内核，继承了 VS Code 的插件生态，同时内置了 AI 对话、代码补全、Builder 模式等能力。
- **为什么选它写前端**：
  - 免费、自带 AI，不用再单独配 GitHub Copilot
  - 对新手友好，报错可以直接丢给 AI 解释
  - 快捷键、插件体系和 VS Code 一致，以后迁移无痛
- **安装步骤**：
  1. 官网下载对应系统安装包（Windows / macOS / Linux）
  2. 一路下一步安装
  3. 登录账号开启 AI 能力
  4. 推荐安装插件：`Prettier - Code formatter`（保存自动格式化）、`Open in Browser`（一键打开网页）
- **一句话**：Trae = VS Code 的壳 + 内置 AI 助手，写前端的"新手村武器"。

## 02 · 谷歌浏览器安装和调试工具

- **为什么前端一定要用 Chrome**：
  - 市场占有率最高，前端兼容性测试的基准
  - DevTools（开发者工具）是所有浏览器里最好用的
  - 前端社区教程、截图、快捷键基本都基于 Chrome
- **安装**：官网下载安装包，一路下一步即可。
- **DevTools 怎么打开**：
  - 快捷键：`F12` 或 `Ctrl + Shift + I`（Mac 是 `Cmd + Option + I`）
  - 右键页面 → 检查
- **常用面板速记**：
  - **Elements**：看和改 HTML 结构、CSS 样式，实时预览
  - **Console**：看报错信息、打印调试、跑 JS 片段
  - **Sources**：看源代码、打断点
  - **Network**：看网络请求，排查接口、资源加载问题
- **新手最常用操作**：Elements 面板里点左上角箭头（或 `Ctrl+Shift+C`），然后点页面上任意元素，就能定位到对应代码。
- **一句话**：DevTools 是前端的"显微镜 + 遥控器"，写网页必须会用。

## 03 · HTML 初体验以及常用配置设置

- **第一个网页**：
  1. 新建文件夹 `my-first-web`
  2. 用 Trae 打开这个文件夹
  3. 新建文件 `index.html`
  4. 输入 `!` 然后按 Tab，Trae 会自动生成 HTML 模板
  5. 在 `<body>` 里写一行 `<h1>Hello World</h1>`
  6. 保存（`Ctrl + S`），双击文件用 Chrome 打开
- **编辑器常用配置**：
  - **保存自动格式化**：设置里搜 `format on save` 打勾，配合 Prettier 插件，写完保存就自动排版
  - **自动补全标签**：安装 `Auto Close Tag`、`Auto Rename Tag` 插件，写 `<div>` 自动补 `</div>`，改开始标签结束标签一起变
  - ** Emmet 语法**：内置的快速写 HTML 的神器
    - `div` → `<div></div>`
    - `div.container` → `<div class="container"></div>`
    - `ul>li*5` → 一个 ul 里五个 li
    - `h1{标题}` → `<h1>标题</h1>`
- **文件命名规范**：
  - 全小写，用连字符 `-` 分隔，不要用中文、空格、大写
  - 首页固定叫 `index.html`，服务器默认找它
- **一句话**：HTML 就是一个纯文本文件，后缀改成 `.html`，浏览器就能读。

## 04 · HTML 简介以及 HTML 文档

- **HTML 是什么**：HyperText Markup Language，超文本标记语言。它不是编程语言，是**标记语言**——用一堆"标签"来描述网页上有什么内容。
- **三个前端基础三件套**：
  - **HTML**：结构 —— 页面上有什么（标题、段落、图片、按钮）
  - **CSS**：样式 —— 长什么样（颜色、大小、位置）
  - **JavaScript**：行为 —— 能干什么（点按钮弹框、轮播、表单校验）
- **HTML 文档基本结构**：
  ```html
  <!DOCTYPE html>
  <html lang="zh-CN">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>我的第一个网页</title>
  </head>
  <body>
    <h1>Hello World</h1>
  </body>
  </html>
  ```
- **逐行解释**：
  - `<!DOCTYPE html>`：告诉浏览器这是 HTML5 文档，必须写在第一行
  - `<html lang="zh-CN">`：整个网页的根标签，`lang` 声明语言，利于 SEO 和屏幕阅读器
  - `<head>`：给浏览器看的配置，用户看不见里面的内容
    - `<meta charset="UTF-8">`：字符编码设为 UTF-8，防止中文乱码
    - `<meta name="viewport" ...>`：移动端适配必备，手机上不会缩放错位
    - `<title>`：浏览器标签页上显示的标题
  - `<body>`：用户真正看到的网页内容，全部写在这里
- **一句话**：HTML 文档 = 文档声明 + 根标签 + 头部配置 + 身体内容。

## 05 · 标签关系以及 AI 工具排错

- **标签的两种关系**：
  - **嵌套关系（父子）**：一个标签里面包着另一个
    ```html
    <div>
      <p>这段文字在 div 里面</p>
    </div>
    ```
    这里 `div` 是父标签，`p` 是子标签。嵌套要正确闭合，不能交叉：
    - 正确：`<div><p>...</p></div>`
    - 错误：`<div><p>...</div></p>`（交叉了，浏览器会自动纠错但结果不可控）
  - **并列关系（兄弟）**：两个标签平级，谁也不包谁
    ```html
    <h1>标题</h1>
    <p>段落</p>
    ```
    `h1` 和 `p` 是兄弟，都直接放在 `body` 里。
- **HTML 标签语法规则**：
  - 标签名用尖括号包起来：`<标签名>`
  - 大部分标签是双标签：开始标签 + 内容 + 结束标签（结束标签多一个 `/`）
  - 少数是单标签（自闭合）：`<br>` 换行、`<img>` 图片、`<meta>`、`<hr>`
  - 标签可以加属性：`<标签名 属性名="属性值">内容</标签名>`
- **AI 工具排错流程**（新手必备）：
  1. 先看 Chrome Console 报什么错（红色那行）
  2. 把报错信息 + 相关代码一起复制给 Trae AI
  3. 问"这是什么意思？怎么改？"
  4. AI 给出修改建议后，自己理解原理再改，不要无脑复制粘贴
- **常见新手错误**：
  - 中文尖括号 `《》` 代替 `<>`
  - 标签名大小写混写（HTML 不区分，但规范要求小写）
  - 漏写结束标签
  - 属性值没加引号
- **一句话**：标签要么嵌套要么并列，交叉嵌套是事故；报错别慌，复制给 AI 先问一遍。

## 06 · 标题和段落标签以及语义化介绍

### 标题标签 h1 ~ h6

- 六级标题，`<h1>` 最大最粗，`<h6>` 最小最细：
  ```html
  <h1>一级标题（页面大标题，一个页面只写一个）</h1>
  <h2>二级标题</h2>
  <h3>三级标题</h3>
  <h4>四级标题</h4>
  <h5>五级标题</h5>
  <h6>六级标题</h6>
  ```
- **注意事项**：
  - `<h1>` 一个页面只出现一次，代表整个页面的主题，对 SEO 很重要
  - 不要跳级：用了 h2 就别直接跳到 h4，层级要连续
  - 不要为了"字大加粗"而用 h 标签——样式问题交给 CSS

### 段落标签 p

- `<p>` 标签表示一个段落：
  ```html
  <p>这是第一段。段落之间会有默认的上下间距。</p>
  <p>这是第二段。浏览器会自动把 p 标签里的文字换行排版。</p>
  ```
- **注意**：HTML 里你敲多个空格、回车换行，浏览器只会显示成一个空格。想换行要用 `<br>`，想分段用 `<p>`。

### 语义化是什么

- **语义化 = 用对的标签做对的事**。不要全用 `<div>` 把页面糊出来，而是：
  - 标题就用 `<h1>~<h6>`
  - 段落就用 `<p>`
  - 导航就用 `<nav>`
  - 侧边栏就用 `<aside>`
  - 文章主体就用 `<article>`
  - 页脚就用 `<footer>`
- **为什么要语义化**：
  1. **SEO 友好**：搜索引擎能看懂页面结构，给你更好的排名
  2. **无障碍访问**：屏幕阅读器靠语义标签读给视障用户听
  3. **代码可读性**：半年后回来自己看，一眼就知道哪块是干嘛的
  4. **团队协作**：同事接手不用猜
- **反例 vs 正例**：
  ```html
  <!-- 反例：全是 div，没有语义 -->
  <div class="title">文章标题</div>
  <div class="para">这是一段正文内容。</div>

  <!-- 正例：语义化标签 -->
  <h1>文章标题</h1>
  <p>这是一段正文内容。</p>
  ```
- **一句话**：语义化不是为了让页面好看，是为了让"人和机器都看得懂"。
