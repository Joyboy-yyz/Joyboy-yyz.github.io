## 01 · 什么是人工智能

- **定义**：让机器模拟人类感知、推理、学习、决策、语言理解等能力的一门学科。
- **三个层次**：
  - 弱人工智能（专用 AI）：下棋、人脸识别、语音助手——当前落地的主力。
  - 强人工智能（通用 AGI）：具备人类级别的通用推理能力，尚未实现。
  - 超人工智能：理论阶段。
- **与传统程序的本质区别**：
  - 传统程序：人写规则 + 输入数据 → 输出答案。
  - AI：喂数据 + 标准答案 → 自动学出规则（模型）→ 对新数据给答案。
- **今天我们站在哪**：弱 AI 大规模落地，以大模型为代表。

## 02 · 机器学习 ML

- **定义**：AI 的子领域，让计算机从数据中自动找规律，而不是把规则一条条写死。
- **三要素**：数据、模型（假设空间）、损失函数 + 优化器（常用梯度下降）。
- **三大类**：
  - 监督学习：有标签 → 分类（垃圾邮件）、回归（房价预测）。
  - 无监督学习：无标签 → 聚类（用户分群）、降维（可视化）。
  - 强化学习：与环境交互，靠奖励/惩罚学习（AlphaGo、游戏 AI）。
- **核心思想**：学一个函数 `f(x) → y`，让它在新样本上也能猜对，即"泛化能力"。

## 03 · 深度学习 DL

- **定义**：ML 的子领域，用多层神经网络自动从原始数据里分层提取特征。
- **"深"在哪**：输入层 → 多个隐藏层 → 输出层。底层学边缘/笔画，中层学纹理/局部，高层学语义/物体。
- **为什么 2012 年后突然爆发**：① 数据量爆炸；② GPU 算力上来；③ 算法突破（ReLU、残差连接、注意力机制）。
- **典型网络**：
  - CNN → 图像
  - RNN / LSTM → 序列（早期 NLP）
  - Transformer → 现在的通用底座
- **与传统 ML 的差别**：传统 ML 靠人做特征工程；DL 把特征工程也一起学了，但吃数据、吃算力。

## 04 · 大语言模型 LLM

- **定义**：基于 Transformer Decoder 架构、在海量互联网文本上做自监督预训练出来的超大规模语言模型。
- **三个"大"**：参数大（数十亿到上万亿）、数据大、计算大。
- **涌现能力**：规模越过某个阈值后，突然具备指令遵循、少样本推理、多语言迁移等之前没有的能力。
- **代表**：GPT 系列、Claude、LLaMA、Qwen、DeepSeek、GLM……
- **本质一句话**：它仍然是在做"预测下一个 token"，只是规模和数据大到让这件小事看起来像通用智能。

## 05 · LLM 大模型预测流程

一次生成一个 token 的完整链路：

1. **分词 Tokenization**：把输入文本切成 token 序列（子词单元）。
2. **词嵌入 Embedding + 位置编码**：每个 token 变成向量，并告诉模型"谁在前谁在后"。
3. **多层自注意力 Self-Attention**：每层让每个 token 与其他所有 token 算关联权重，捕捉上下文。
4. **前馈网络 FFN**：逐位置做非线性变换。
5. **残差连接 + LayerNorm**：让几十上百层的网络还能训得动。
6. **输出投影**：最后一个位置的隐状态 → 词表大小的 logits → Softmax 得到下一个 token 的概率分布。
7. **采样**：按 Temperature / Top-p / Greedy 选出下一个 token。
8. **拼回去继续猜**：把新 token 追加到输入，回到第 1 步，直到遇到结束符或达到最大长度。

> 一句话：LLM 就是"读完整句话 → 猜下一个字 → 把这个字拼回去 → 再猜下一个"的循环。

## 06 · AI 幻觉 Hallucination

- **定义**：模型输出看起来流畅、自信、像模像样，但事实是错的、编的、张冠李戴的。
- **为什么会产生**：
  - 训练目标是"预测下一个 token"，不是"求真"——它学的是语言模式，不是事实本身。
  - 训练数据里本来就混着错误、偏见、过时信息。
  - 对长尾/冷门知识没见过，只能"编得像"。
  - 采样温度越高，越容易自由发挥。
- **典型症状**：编造不存在的论文/链接/法条、把 A 的事迹安到 B 头上、数值一本正经地错。
- **缓解手段**：
  - **RAG**：先检索可信资料，再让模型基于资料回答。
  - 要求模型给出处、让它自我校验。
  - 降低 Temperature，用更确定的采样。
  - 医疗/法律/财务等关键信息必须人工复核。

## 今日小结

从 AI → ML → DL → LLM，是一个**范围逐层收窄、能力逐层聚焦**的圈：

- AI 是最大的圈；
- ML 是其中"用数据学"的那一支；
- DL 是 ML 里"用深层神经网络"的那一支；
- LLM 是 DL 里"专门做语言、且规模极大"的那一个。

理解了"下一个 token 预测"这个本质，再回头看幻觉——它就不是一个 bug，而是这个目标函数自带的"性格"。知道它为什么会这样，才知道该怎么用、怎么防。
