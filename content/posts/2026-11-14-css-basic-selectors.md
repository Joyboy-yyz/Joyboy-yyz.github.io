## 23 · 第二篇案例收尾 + 样式表的三种分类

HTML 部分告一段落，Pink 老师带做了一个综合案例回顾。从今天起正式进入 CSS（Cascading Style Sheets，层叠样式表）——负责"网页长什么样"：颜色、字体、间距、布局、动画……

CSS 代码写在哪儿？一共有 **三种样式表**，优先级和适用场景各不相同：

### ① 行内样式表（内联样式）

直接写在标签的 `style` 属性里，只对当前这一个标签生效：

```html
<p style="color: red; font-size: 20px;">我是红色大字</p>
```

- 优点：权重最高，当场就能覆盖任何外部样式；
- 缺点：**结构和样式混在一起**，改一个字都要翻 HTML，十行页面九行样式，没法复用；
- 适用：临时调试、JS 动态改样式，**正经项目基本不用**。

### ② 内部样式表（内嵌样式表）

写在 HTML 的 `<head>` 里，用 `<style>` 包起来，只对**当前这一个页面**生效：

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>内部样式表示例</title>
  <style>
    p {
      color: blue;
      line-height: 1.6;
    }
  </style>
</head>
<body>
  <p>整个页面的 p 都变蓝了</p>
</body>
</html>
```

- 优点：HTML 和 CSS 至少分开了，同一个页面里能复用；
- 缺点：多个页面想共用样式就得复制粘贴，改一处要改 N 个文件；
- 适用：写 Demo、单页面小作业。

### ③ 外部样式表（最推荐）

把 CSS 单独存成一个 `.css` 文件，在 HTML 里用 `<link>` 引入：

```html
<head>
  <link rel="stylesheet" href="css/style.css">
</head>
```

`style.css`：

```css
/* 整个网站所有页面都能共用这份样式 */
p {
  color: #333;
  line-height: 1.6;
}
```

- 优点：**结构（HTML）和表现（CSS）彻底分离**，一个 css 文件全站复用，浏览器还会缓存它，加载更快；
- 缺点：多一个文件要管；
- 适用：**正式项目一律用外部样式表**。

### 三种样式表的覆盖关系

大白话记三句话：

1. **行内样式权重最高**，谁来了都不好使；
2. **内部样式表和外部样式表是同一档权重**，谁写在后面听谁的——注意顺序看的是 `<link>` 和 `<style>` 在 `<head>` 里谁排在后面，**后出现的覆盖先出现的**；
3. 同一份样式表里，**相同选择器后写的覆盖先写的**（这就是"层叠"两个字的意思）。

> 面试常考：「行内、内嵌、外链谁优先级高？」标准答案：行内 > 内嵌/外链（后写的覆盖先写的）。

## 24 · 类型选择器（元素选择器）与 CSS 注释

### 类型选择器

直接写标签名，选中页面上**所有**该标签：

```css
/* 选中页面上所有的 <p> */
p {
  color: #333;
}

/* 选中所有 <h1> */
h1 {
  font-size: 32px;
}
```

- 也叫**元素选择器**，因为选的是 HTML 元素；
- 特点：一选就是"全班同学"，无法只选中某一个；
- 权重最低（0,0,1），后面学了类选择器就很少单独用它了。

### CSS 注释怎么写

CSS 注释语法和 HTML 不一样，用 `/* ... */`，**不能嵌套**：

```css
/* 这是一行注释，给人看的，浏览器会忽略 */

/*
  这是多行注释
  可以写好几行
  一般用来标注模块
*/

/* 下面这种嵌套是错的！ */
/* /* 内层注释 */ */
```

Pink 老师课上强调的"AI 注释"，其实就是**规范的注释写法**：每个模块用醒目的分隔注释隔开，变量、颜色、布局分区都标清楚。这样以后无论是自己回头看，还是把代码丢给 AI 帮你改，都能秒懂结构：

```css
/* ====================== 基础重置 ====================== */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

/* ====================== 顶部导航区 ====================== */
.nav {
  height: 60px;
  background: #fff;
}

/* ====================== 主体内容区 ====================== */
.main {
  width: 1200px;
  margin: 0 auto;
}
```

> 好习惯：注释写"为什么这么做"，而不是翻译代码本身。`/* 这里用 flex 是为了让小屏也能自动换行 */` 比 `/* 设置 display 为 flex */` 有用一百倍。

## 25 · 类选择器（最常用）

类选择器用 `.` 开头，选中所有带对应 `class` 属性的元素：

```css
.box {
  width: 200px;
  height: 200px;
  background: skyblue;
}
```

```html
<!-- 谁想要这个样式，就给谁加 class="box" -->
<div class="box">我是盒子一</div>
<p class="box">我是 p 标签，但也能用 box 样式</p>
```

### 类选择器的三个关键特性

1. **class 可以重复使用**——十个元素都能加 `class="box"`，这是它比类型选择器灵活的地方；
2. **一个元素可以有多个 class**，用空格隔开：

   ```html
   <div class="box highlight">我既有 box 的样子，又有 highlight 的高亮</div>
   ```

   ```css
   .box { width: 200px; height: 200px; }
   .highlight { border: 2px solid orange; }
   ```

3. **命名见名知意**：用英文小写 + 短横线，比如 `.nav`、`.news-list`、`.card-title`；**不要用中文、空格、驼峰**，更不要起 `.red1`、`.test` 这种莫名其妙的名字。

```css
/* ✅ 好的命名 */
.nav-bar { ... }
.article-title { ... }

/* ❌ 坏的命名 */
.red1 { ... }      /* 哪天不红了怎么办 */
.test { ... }      /* 三个月后自己都不知道这是啥 */
```

> 大白话：类型选择器是"全班统一着装"，类选择器是"发红袖章"——想给谁加就给谁加，一个人还能同时戴好几枚袖章。

## 26 · id 选择器与通配符选择器

### id 选择器

用 `#` 开头，选中**那个** id 对应的元素：

```css
#header {
  height: 60px;
  background: #222;
}
```

```html
<header id="header">网站头部</header>
```

铁律：

- **id 在一个页面里必须唯一**，全页只能出现一次 `id="header"`，写两个浏览器也不报错，但这是规范不允许，JS 用 `getElementById` 也只会找到第一个；
- 一个元素**只能有一个 id**（不能像 class 那样空格分隔写两个）；
- id 选择器权重很高（1,0,0），写上去基本盖不住，所以做样式一般**优先用 class，id 留给 JS 和锚点跳转用**。

```html
<!-- 锚点跳转：点链接滚到 id=chapter2 的位置 -->
<a href="#chapter2">跳到第二章</a>
<h2 id="chapter2">第二章 通配符</h2>
```

### 通配符选择器 `*`

`*` 选中页面上**所有元素**，没有之一：

```css
* {
  margin: 0;
  padding: 0;
}
```

- 最常见用途：**清零浏览器默认样式**——浏览器自动给 `<body>`、`<h1>`、`<ul>` 加了一堆默认 margin/padding，先全清零再自己写，样式才不会莫名其妙跑偏；
- 但它会选中每个元素（包括几百个 `<span>`），有一点点性能开销，正式项目更常用成熟的 Reset / Normalize.css，初学阶段用 `*` 图个方便完全 OK。

## 四种基础选择器对比

| 选择器 | 语法 | 选中谁 | 能否重复 | 权重 | 大白话 |
|---|---|---|---|---|---|
| 类型选择器 | `p {}` | 所有 `<p>` | 全选 | (0,0,1) | 全班统一 |
| 类选择器 | `.box {}` | 所有 `class="box"` | 可重复、可多 class | (0,1,0) | 红袖章，随便发 |
| id 选择器 | `#nav {}` | `id="nav"` 的那一个 | 全页唯一 | (1,0,0) | 身份证号，唯一 |
| 通配符 | `* {}` | 页面所有元素 | 全选 | (0,0,0) | 清空全场 |

> 权重口诀（先有个印象，后面还要展开）：**`#` > `.` > 标签 > `*`**。权重高的压过低的，同权重后写的压先写的。

## 一个 demo 把今天全串起来

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>CSS 选择器练习</title>

  <!-- 外部样式表：实际项目把下面这段拆到 style.css -->
  <link rel="stylesheet" href="css/style.css">

  <style>
    /* 内部样式表：演示用 */
    * { margin: 0; padding: 0; }        /* 通配符：清零 */

    body { padding: 20px; font-family: sans-serif; }

    /* 类型选择器：所有 h2 都长这样 */
    h2 {
      color: #222;
      border-bottom: 2px solid #eee;
    }

    /* 类选择器：卡片 */
    .card {
      padding: 16px;
      margin: 12px 0;
      border-radius: 8px;
      background: #f7f7f7;
    }

    .highlight { border-left: 4px solid orange; }  /* 第二个 class */

    /* id 选择器：只有头部用 */
    #header {
      height: 50px;
      line-height: 50px;
      background: #2c3e50;
      color: #fff;
      padding: 0 16px;
    }
  </style>
</head>
<body>

  <!-- id 全页唯一 -->
  <div id="header">振灿的 CSS 练习页</div>

  <h2>一、类选择器：普通卡片</h2>
  <div class="card">我是一张普通卡片</div>

  <h2>二、两个 class 叠着用</h2>
  <div class="card highlight">我既有 card 的样式，又有 highlight 的橙色左边框</div>

  <h2>三、类型选择器：所有段落统一字号</h2>
  <p>第一段文字，被 p 类型选择器选中。</p>
  <p>第二段文字，同样被选中。</p>

  <!-- 行内样式：优先级最高，临时盖一下 -->
  <p style="color: red;">我是行内样式的红色段落，谁也盖不住我。</p>

</body>
</html>
```

## 今日踩坑小结

1. **三种样式表别混用**：学习 Demo 用内部样式表（一个文件能跑），正式项目一律外部样式表 `<link>`；行内样式只留给 JS 动态改和临时调试。
2. **内部 vs 外部同权重，看谁后写**：`<link>` 和 `<style>` 在 `<head>` 里的顺序决定胜负，别搞反了。
3. **CSS 注释是 `/* */`，不是 `<!-- -->`**，也不能嵌套；注释要写"为什么"，别翻译代码。
4. **class 可以重复、可以多个空格隔开；id 全页唯一、只能一个**——这是面试高频对比题。
5. **写样式优先 class，别滥用 id**：id 权重太高（1,0,0），以后想覆盖特别痛苦，id 留给 JS 和锚点。
6. **`* { margin:0; padding:0 }` 是初学神器**，但心里要知道它性能不高，以后换 Normalize.css。
7. 类名用小写英文短横线（`.news-list`），别用中文、别用 `red1` 这种自嗨命名。
